# 💰 Персональный трекер финансов, целей и расходов

🌐 **Live Demo на GitHub Pages**: [https://skeepyki.github.io/tracking-finances/](https://skeepyki.github.io/tracking-finances/)

---

Работает полностью на стороне браузера (без бэкенда и баз данных для посторонних), сохраняя все данные локально в `localStorage`. Оптимизировано для бесплатного хостинга на **GitHub Pages**.

---

## 🚀 Возможности

1. **Счета и Кошельки**:
   - Поддержка карт, наличных, накопительных счетов, брокерских счетов и криптокошельков.
   - Удобные переводы между счетами без искажения статистики доходов и расходов.
   - Отображение суммарного капитала (Net Worth).

2. **Финансовые цели и Копилки**:
   - Автоматический расчет требуемой суммы пополнения в месяц и неделю до дедлайна.
   - Вехи достижения цели (25%, 50%, 75%, 100%).
   - Быстрое пополнение копилок.

3. **Учет операций и Бюджетирование**:
   - Доходы, Расходы и Переводы с фильтрацией и поиском.
   - Быстрые шаблоны частых трат в 1 клик (Кофе, Продукты, Такси и т.д.).
   - Месячные бюджеты по категориям с цветовой индикацией перерасхода.

4. **Аналитика и Финансовое здоровье**:
   - Интерактивные круговые диаграммы структуры расходов и доходов.
   - Столбчатые графики доходов vs расходов за 6 месяцев.
   - График динамики общего капитала (Net Worth).
   - Расчет нормы сбережений (Savings Rate) и финансовой подушки безопасности (в месяцах жизни).

5. **Безопасность и Резервные копии**:
   - Все данные хранятся только у вас в браузере.
   - Экспорт / импорт полной базы в JSON в 1 клик.
   - Экспорт истории операций в CSV/Excel.
   - Тёмная и светлая темы с эффектом Glassmorphism.

## 💻 Запуск локально

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

## 🌐 Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него проект:
   ```bash
   git init
   git add .
   git commit -m "feat: finance tracker app"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
2. В репозитории на GitHub перейдите в **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите Source: **GitHub Actions**.
4. После пуша GitHub Actions автоматически соберет проект и предоставит готовую ссылку на сайт!
